# 画像のデジタル化君２

絵を描き、標本化・量子化・符号化を順に体験する学習用アプリです。前作「画像のデジタル化君」の配色と、左に描画・右に加工結果を並べる構成を引き継いでいます。

## 使い方

`index.html` をブラウザで開いてください。初期状態は白紙・黒ペンです。外部ライブラリやビルドは不要です。HTML単体で動き、保存後はオフラインで使えます。画像の外部送信・アクセス解析はありません。

- 標本化：青い操作欄で縦・横4〜256画素を切り替え。各マスの中心の色を取り出し、画素の区切りを表示（64画素まで）。量子化はオレンジ、符号化は紫で区別し、操作中の段階と欄を強調。
- 量子化：カラー／グレースケール／モノクロ（白黒２値）。通常はカラー24 bit、グレースケール8 bit、モノクロ1 bit／画素。カラーとグレースケールは1〜8 bit／成分または画素に変更可能。色の設定を変えると量子化へ移動し、標本化だけの段階では画素数のみを表示。
- 符号化：右の比較欄に画像全体の２進数と総桁数を表示。上下左右にスクロール・全文コピー可能。改行は画像の行の区切りで、総桁数には含めません。画素をタップしたときだけ、標本値・量子化した整数・固定長の２進数をポップアップ表示。矢印キーでも選択可能。
- 解像度：「同じ画像を、大きく印刷すると？」に絞り、印刷する１辺の長さを変えるスライダー１本で比較。画素数を固定し、2.54〜10.16 cmに広げたときのppiと画素の大きさを確認。小さく／２倍／４倍のボタンでも変更可能。
- ペンの色・RGB・太さ、20回までの元に戻す、全消去。サンプル画像はありません。
- 「描画・デジタル化」「解像度・印刷」「使い方・保存」の３タブ。iPad横向きではヘッダーと比較画面をコンパクトに表示。
- 量子化後のPNG・学習用ビット列テキスト・オフライン用HTMLの保存。

## 学習モデル

アナログの原画には画素数やビット数がないため、左の原画欄にはそれらを表示しません。ただし画面上での描画自体はデジタル画像です。実物を直接取り込むのではなく、デジタル化前の原画を表す欄として処理をモデル化します。量子化では最も近い段階に丸め、グレースケールの明るさは `0.299R + 0.587G + 0.114B` の四捨五入です。符号化だけでは見た目は変わりません。

理論データ量は `幅 × 高さ × bit/画素 ÷ 8`。ヘッダー・圧縮・透過情報は含みません。小数Bの場合、実際に格納するバイト数は切り上げが必要です。書き出すテキストは０と１を文字で表した学習用データで、理論データ量とは異なります。

画像の画素密度はppi、プリンターの点の密度はdpiとして区別します。印刷サイズの比較は縮尺表示で、画面上の実寸ではありません。PNG保存時に印刷解像度のメタデータは設定しません。

## ダウンロード・公開

`download.html` は他のシリーズと同じカード・青いボタン・確認ダイアログのダウンロードページです。アクセスだけでは保存を始めません。

## 検証

Chromiumで、描画・タッチ・元に戻す、既知のRGB値による標本化／量子化／符号化、印刷サイズとppiの関係・画素数固定、画像全体の２進数・総桁数（最大1,572,864桁）・クリップボードへのコピー・画素ポップアップ、PNG／ビット列／HTMLの保存、オフラインHTMLの再実行、スマートフォン・タブレット幅、iPad横向き相当（1024×768、1180×820、1194×834、1366×1024）とブラウザー領域が狭い1024×680での表示・タブ操作を検証しています。iPad・Apple Pencil・Safariの実機確認は未実施です。

再確認する場合はPython版PlaywrightとChromiumを用意し、静的サーバーを起動して `python tests/browser_check.py http://localhost:8123` を実行してください。テストは既定で `/usr/bin/chromium` を使います。
